# Alexa+ add-on package

`addon-package/addon.json` is a **draft** written from the field list in the Alexa+ MCP quickstart (2026-10-08). The CLI's own `alexa-ai new mcp` output is authoritative: once CLI access works, scaffold with it and copy these values in. Key names in the icon size and asset objects may differ from the generated template.

- Endpoint: `<ServerUrl>/mcp` (Streamable HTTP, MCP 2025-11-25)
- Privacy / terms: `<ServerUrl>/privacy`, `<ServerUrl>/terms`
- Media: `<ServerUrl>/media/<file>`, generated by `python3 scripts/make-addon-media.py` (provisional art until BRAND.md)

Deploy once CLI access is granted:
```
alexa-ai new mcp --name "Homebase" --locale en-US --mcp-server-url "<ServerUrl>/mcp"
alexa-ai deploy
```
